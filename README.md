# SCSE2103: Data Structures and Algorithms

**Section:** 03
**Academic Session/Semester:** 2026/2027/1  
**Credit Hours:** 3  
**Prerequisites:** SCSE1013, SCSE1224  
**Faculty:** School of Computing, Faculty of Computing, Universiti Teknologi Malaysia

-----

## 📖 Course Overview

This course provides fundamental and intermediate knowledge of data structures and algorithms using **C++**. Key topics include abstract data types, recursion, algorithm efficiency (Big O analysis), sorting, searching, linear data structures (linked lists, stacks, queues), and non-linear data structures (trees, BST).
